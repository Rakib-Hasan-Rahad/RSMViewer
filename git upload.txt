RSMViewer GitHub Upload Instructions
=====================================

Open Terminal and run:

cd "/Users/rakibhasanrahad/Desktop/IMPORTANT FILES 2026/RSMViewer-PyMOL PLUGIN"

git status

Stage only the files you intend to upload:

git add README.md DEVELOPED.md docs/TUTORIAL.md

Review the staged changes:

git diff --cached --stat
git diff --cached --check

Commit and upload:

git commit -m "Update documentation"
git push origin main

Check that local main and GitHub are synchronized:

git fetch origin
git rev-list --left-right --count origin/main...main

Expected result:

0       0

Ignoring a file or folder
-------------------------

Add the file or folder to .gitignore. Examples:

private_notes.txt
external/rmsx/RNAVIEW/
**/RNAVIEW/
output/local_results/

Check whether Git ignores a path:

git check-ignore -v path/to/file

If the path was already tracked, remove it from Git but keep it locally:

git rm -r --cached path/to/folder
git add .gitignore
git commit -m "Ignore local data"
git push origin main

Important:

Do not use git add -A unless you have reviewed all deletions, generated files,
large datasets, and local benchmark outputs shown by git status.
